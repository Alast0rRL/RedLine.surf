# Эффекты сайта и откуда берётся «вау»

«Вау» на сайте создают не отдельные эффекты, а их сочетание: всё на странице медленно живёт само,
отзывается на курсор и прокрутку, и всё выдержано в одном чёрно-красном стиле.

## 1. Первый экран (hero): впечатление за первые 3 секунды

| Эффект | Где | Почему работает |
|---|---|---|
| **Красные линии** `<rl-red-lines>` | `packages/redline-ui/src/red-lines.*` | Фирменный знак. Две диагонали въезжают из-за краёв экрана, потом медленно «дышат». Кажется, что движется весь экран, хотя анимируются две линии. CSS на композиторе, вне экрана ставится на паузу. |
| **Волны внизу** | `hero.html`, `.waves`/`.parallax` в `assets/site.css` | Четыре слоя одной SVG-волны с разной прозрачностью и скоростью (7/10/13/20 с) и отрицательными задержками. Слои никогда не совпадают, получается объёмная живая вода. Плюс мягкий переход от hero к следующей секции вместо резкой линии. |
| **Плавающие пятна (blob)** | `.blob` | Два огромных размытых красных пятна медленно плывут 25 с туда-обратно. Фон кажется глубоким и тёплым, хотя пятна почти не видны. |
| **Живой мир** | `static/js/world.js`, `<canvas id="world">` | Весь фон — изометрический Minecraft-мир на canvas: река с деревней, поле пшеницы, пастбище с овцами, костёр с курами, шахта с вагонеткой. Вода переливается, дым костра — серые квадраты как в игре, огонь у факелов. Смена темы = быстрый закат/рассвет (2,4 с): солнце садится, выходит луна и звёзды, в окнах загорается свет. Ночью курсор — факел, освещает мир вокруг. Лёгкий параллакс за мышью. Облака включаются флагом `CFG.clouds`. Рисуется, только пока hero виден; `prefers-reduced-motion` — статичный кадр. |
| **Фон под миром** | `.hero-background`, `.world-vignette` | Ровный градиент плюс радиальная виньетка под заголовком, чтобы текст читался поверх мира. |
| **Каскадное появление** | `.reveal` + `--reveal-delay` | Значок, заголовок, онлайн, IP, кнопки выезжают снизу по очереди с шагом 100 мс и кривой `ease-out-expo` (быстрый старт, долгое мягкое торможение). Лесенка выглядит как режиссура. |
| **Живой онлайн** | `#online-count`, `/api/status` | Пока данные грузятся — переливающийся скелетон. Потом цифра и зелёная точка со свечением. Сайт показывает, что сервер жив прямо сейчас. |
| **Крупная типографика** | Montserrat 900, `tracking-tighter`, uppercase | Огромный плотный заголовок с красным словом — постерная подача. |

## 2. Отклик на действия: сайт «чувствует» посетителя

| Эффект | Где | Почему работает |
|---|---|---|
| **Свечение за курсором** | `#glow-overlay` + `site.js` (glow) | Красный радиальный свет догоняет мышь с инерцией (10% расстояния за кадр). Над кнопками и ссылками пятно расширяется и становится ярче, как подсветка. Самый сильный «вау» на ПК. На телефонах выключен. |
| **Плавная прокрутка Lenis** | `static/vendor/lenis.min.js` | Колесо мыши даёт плавный ход с экспоненциальным торможением (1,2 с), как в дорогих лендингах. Ссылки меню доезжают до секции так же плавно. |
| **Кнопки «приподнимаются»** | `hover:-translate-y-2`, тень с красным | Кнопка подпрыгивает к курсору, под ней красная тень-свечение, при нажатии она «вдавливается» (`active:scale-95`). |
| **Конфетти** | `canvas-confetti`, «Принять и скопировать IP» | Награда за главное действие: залп красно-белого конфетти. Запоминается и закрепляет «я в деле». |
| **Тост «Скопировано»** | `#toast` | Подтверждение всплывает снизу и само уходит. |
| **Тема день/ночь** | `data-theme-toggle` | Мгновенная смена с плавным переходом цветов (500 мс). Иконка поворачивается при наведении. |

## 3. Секции ниже: интерес не падает при прокрутке

| Эффект | Где | Почему работает |
|---|---|---|
| **Появление блоков при прокрутке** | `.reveal` + IntersectionObserver | Каждый блок проявляется, когда до него доезжаешь. Карточки в ряду идут волной (задержка по колонке). |
| **Стеклянные карточки** | `backdrop-blur-md`, `bg-white/[0.03]`, скругление 40px | Полупрозрачные карточки с размытием фона, при наведении — красная рамка и подъём. |
| **Карта: чёрно-белое → цвет** | `#map`, `grayscale` → `grayscale-0` + `scale-110` | При наведении карта оживает: появляется цвет, лёгкий зум, кнопка «Открыть карту». |
| **Пульсирующая точка** | `animate-ping` | «Обновляется в реальном времени» подкреплено живым индикатором. |
| **Бесконечная галерея** | `#gallery-track` | Лента без конца с инерционной кривой, на телефоне свайп. При наведении фото приближается, темнеет и показывает лупу. |
| **Просмотр фото** | `<dialog id="lightbox">` | Полноэкранный тёмный просмотр, смена фото с мягким миганием, стрелки клавиатуры, Esc. |
| **Аватарки команды** | mc-heads, `group-hover:scale-110` | Пиксельные головы скинов увеличиваются при наведении на карточку, цветные бейджи ролей. |
| **Кнопка «наверх»** | `#back-to-top` | Выезжает снизу после 500 px прокрутки и плавно (через Lenis) везёт наверх. |

## Потом / отложено

- **Пасхалка: ломание блоков.** Клик по блоку мира — блок трескается (стадии разрушения) и ломается с частицами, как в игре; можно звук. Идея одобрена, делаем позже. Точка входа — `window.__redlineWorld` в `world.js` (нужен обратный пересчёт экранных координат в клетку `x,y,z`).

## Правила, чтобы эффекты не превратились в тормоза

- Анимировать только `transform` и `opacity` (и CSS-переменные свечения), не `width/top/margin`.
- Бесконечные анимации — на CSS. JS-циклы (свечение) крутятся, только пока что-то меняется.
- `prefers-reduced-motion`: всё движение выключается, контент виден сразу. Не ломать.
- Без JS (`<html>` без класса `.js`) блоки `.reveal` видимы — страница не бывает пустой.
- Никаких CDN: шрифты и библиотеки в `static/vendor`, собираются `pnpm --filter @redline/site build`.
- Цвета и тайминги — из токенов `packages/redline-ui/src/tokens.css` (`--rl-red-500`, `--rl-ease-out-expo`, …).
